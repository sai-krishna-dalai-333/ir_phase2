# Project Title

IR_Phase2

## Project Structure

- **src/**: Contains Java source files.
- **bin/**: Contains compiled `.class` files.
- **input/**: Contains input files.
- **output/**: Contains output files, including `forward_index.txt` and `inverted_index.txt`.

## Execution Steps

1. **Compile Java Files**:
   ```sh
    javac -d bin src/*.java

2) Run the Main Class:
command : 

 java -cp bin Main

3) After running the Java files, the following output files will be generated in the output directory:

forward_index.txt
inverted_index.txt
